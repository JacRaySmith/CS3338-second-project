# CS3338-second-project

A simple one-page website forked from CS3338-Awesome-Website for CS 3338 (Software Engineering Tools), Lab Activity 2.

This repo is used to practice forking, cloning, branching, pull requests, and resolving merge conflicts with Git and GitHub.

## Files

- `index.html` - the web page
- `git_log.txt` - output of `git log --all --branches`
- `repo-location.txt` - link to this repository on GitHub
